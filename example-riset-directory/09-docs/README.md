# 09-docs

Folder ini berisi dokumen perencanaan penelitian dan rincian langkah kerja per tahap untuk riset "Analisis Performa Algoritma Hibrida AHP-TOPSIS (Noise Injection)".

## Berkas

- `rencana-penelitian.md`: Ikhtisar abstrak, tujuan, metrik pengujian, dan linimasa keseluruhan.
- `tahap-1-persiapan-dataset.md`: Detail pengolahan 140 dataset riil & 10.000 dataset sintetis.
- `tahap-2-implementasi-skrip.md`: Struktur skrip Python CLI (`data_loader`, `ahp_topsis`, `sensitivity_test`, `logger`).
- `tahap-3-pengujian-noise.md`: Prosedur *stress test* injeksi deviasi bobot $\pm 10\%$ hingga $\pm 50\%$.
- `tahap-4-analisis-hasil.md`: Pengukuran metrik *Spearman Rank*, *Kendall Tau*, dan *runtime* komputasi.
- `tahap-5-publikasi.md`: Persiapan kompilasi draf naskah jurnal akhir.
